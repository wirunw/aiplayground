# AI Playground for Pharmacy

ชุดคำสั่ง (prompt) แบบ R–T–F และข้อมูลจำลองสำหรับ workshop "AI Playground for Pharmacy" ฝึกใช้ AI ในงานเภสัชกรรม ออกแบบและเรียบเรียงโดย ดร.ภก.วิรุณ เวชศิริ (อ.หมี) อาจารย์ประจำคณะเภสัชศาสตร์ มหาวิทยาลัยธรรมศาสตร์

นำไปใช้สอนหรือแชร์ต่อได้ โปรดให้เครดิตผู้จัดทำทุกครั้ง

เปิด `index.html` บนมือถือหรือคอมพิวเตอร์ เลือกกิจกรรม กรอกช่องที่ต้องการ แล้วกดคัดลอกคำสั่งไปวางใน Gemini ได้เลย ข้อมูลจำลองที่ใช้ในโจทย์ฝังอยู่ในคำสั่งแล้ว ไม่ต้องอัปโหลดไฟล์

ข้อมูลทุกชุดในโฟลเดอร์ `data` เป็นข้อมูลสมมติเพื่อการอบรมเท่านั้น ไม่มีข้อมูลผู้ป่วยจริง ส่วนเอกสารความรู้ผู้ป่วย (ไฟล์ 05) ทำไว้เป็นวัตถุดิบของโจทย์ ควรให้เภสัชกรตรวจทานก่อนนำไปใช้จริง

## ในโฟลเดอร์นี้

- `index.html` หน้าเว็บชุดคำสั่งสำหรับผู้เข้าร่วม
- `data/` ข้อมูลจำลอง: อัตรากำลังและเวลารอรับยา, รายงานความคลาดเคลื่อนทางยา, ยาคงคลัง, ค่าฝุ่นและราคาน้ำมันสำรอง, เอกสารความรู้ผู้ป่วย และรายชื่อ API ที่ใช้ได้
- `assets/avatar.webp` รูปประจำตัวผู้จัดทำ (พื้นโปร่งใส ขนาดเล็ก)
- `src/` ต้นฉบับหน้าเว็บ แก้ที่ `src/template.html` แล้วรัน `python3 src/build.py` เพื่อสร้าง `index.html` ใหม่
